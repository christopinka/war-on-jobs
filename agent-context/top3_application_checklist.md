# Top 3 application checklist

## 1) UST
- Company: UST
- Website: https://www.ust.com
- Target role: Platform Engineer / Cloud Engineer
- Why it fits: direct employer, healthcare cloud platform, platform engineering lane
- Resume match: cloud engineering, Kubernetes, AWS, Terraform, CI/CD, platform operations, healthcare or regulated environment
- Apply action: search for "Platform Engineer" or "Cloud Engineer" on UST careers; apply with a platform-focused resume
- Follow-up: check for direct role page within 48 hours; if no role, message recruiter / hiring manager through LinkedIn only if relevant

- Why it fits: direct employer, healthcare/regulated customer platform, systems engineering lane

## 3) Tebra
- Company: Tebra
- Website: https://www.tebra.com
- Target role: Platform / DevOps / Cloud Engineer
- Why it fits: healthcare SaaS platform, direct employer, likely strong platform and cloud stack
- Resume match: healthcare SaaS, AWS, Kubernetes, Terraform, Python, SQL, DevOps, deployment automation
- Apply action: apply to platform, cloud, or SRE roles; keep the resume centered on healthcare tech and platform reliability
- Follow-up: track status in the queue and apply to any matching platform postings within 72 hours

## General application rules
- Apply only to direct employer roles
- Reject any staffing, agency, or vendor postings
- Emphasize cloud/platform operations, not generic backend work
- Keep the resume aligned to healthcare or regulated software environments when possible
- Track each application in the queue with status updates
